# Как обновить репозиторий и собрать Telegrios v1.3

## Нужно заменить ровно 2 файла на GitHub

Все Java-классы, иконки и темы теперь **встроены внутрь** `apply_overlay.py`,
поэтому обновление сводится к двум файлам:

### 1. `overlay/tools/apply_overlay.py`
GitHub → репозиторий **dezeror/spectra-mod** → `overlay/tools/apply_overlay.py` →
карандаш (Edit) → выделить всё, удалить, вставить содержимое нового
`apply_overlay.py` (файл ~275 КБ — вставляйте через «Replace file», не через
строку) → Commit changes.

> Если через веб-интерфейс большой файл не вставляется — удалите файл
> (File → Delete), затем «Add file → Upload files» и перетащите новый файл,
> путь `overlay/tools/` сохранится автоматически.

### 2. `.github/workflows/spectra-build.yml`
Открыть файл → Edit → заменить всё содержимое на новое (имя «Telegrios Build»,
артефакты Telegrios-APK / Telegrios-keystore, APK `Telegrios-v1.3-release-arm64.apk`)
→ Commit.

### Старые файлы удалять НЕ обязательно
`overlay/java/…`, `overlay/res/…`, `overlay/theme/…` больше не читаются
скриптом — они остались в репозитории как история v1.0 и на сборку не влияют.
(При желании можно удалить папки `overlay/java`, `overlay/res`, `overlay/theme`
для чистоты.)

## Запуск сборки
1. GitHub → вкладка **Actions** → слева **Telegrios Build** → **Run workflow** →
   build_type: release → Run.
2. Ждать ~40–70 минут (зелёная галочка).
3. Внизу страницы запуска → **Artifacts** → скачать **Telegrios-APK** →
   внутри `Telegrios-v1.3-release-arm64.apk`.
4. Скачать **Telegrios-keystore** и сохранить навсегда (для обновлений «поверх»).

## Установка на телефон
1. **Удалите старое приложение Spectra** (новый пакет `org.telegrios.messenger` —
   это отдельное приложение, сосуществовать они не будут из-за одинакового
   названия в лаунчере; удаление старой также уберёт её баги и кэш).
2. Установите `Telegrios-v1.3-release-arm64.apk` (разрешите установку).
3. Запустите. При первом входе введите номер и код (это новый клиент —
   аккаунт Telegram тот же, данные в облаке сохранятся).

## Если приложение снова закроется
Теперь диагностика v3 **гарантированно покажет отчёт**:
- сразу после сбоя приложение само откроется на синем экране
  «Telegrios — отчёт о сбое» с трассировкой;
- нажмите **«Поделиться»** и отправьте текст разработчику (или
  **«В Загрузки»** → файл `telegrios_crash.txt`);
- если экран не появился — просто запустите приложение ещё раз: оно стартует
  в безопасном режиме и покажет отчёт вместо падения;
- пришлите этот текст — в нём точная причина сбоя (stack trace + milestones).
