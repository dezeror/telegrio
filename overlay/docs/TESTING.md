# Spectra — тестирование через ADB

Песочница сборки не имеет Android-устройства/эмулятора, поэтому ниже — готовый чеклист
для проверки собранного APK на вашем устройстве или в эмуляторе.

## 1. Подготовка

```bash
# устройство: включить «Отладку по USB» (Настройки → Для разработчиков)
adb devices                     # устройство должно быть в списке
adb install -r path/to/app-arm64-debug.apk
```

Подписанный release-APK (из CI): `Spectra-release-signed.apk` — ставится так же.
Release без подписи (`*.apk` unsigned) устанавливать нельзя — сначала подпишите:

```bash
zipalign -f -p 4 unsigned.apk aligned.apk
apksigner sign --ks my.jks --ks-key-alias alias --out Spectra.apk aligned.apk
```

## 2. Первый запуск

```bash
adb shell monkey -p org.spectra.messenger -c android.intent.category.LAUNCHER 1
adb logcat -c && adb logcat | grep -iE "spectra|AndroidRuntime|FATAL"
```

Чеклист UI:
- [ ] Иконка лаунчера — неоновая «S» на чёрном фоне (адаптивная иконка).
- [ ] Название приложения под иконкой — «Spectra».
- [ ] Авторизация по номеру телефона проходит (используется публичный FOSS API-ключ 12834;
      для постоянного использования зарегистрируйте собственный на my.telegram.org).
- [ ] Тема по умолчанию — AMOLED-чёрный с зелёными акцентами.

## 3. Spectra Settings

Меню Nagram → «Spectra Settings» (в конце списка). Чеклист:
- [ ] Открывается хаб с логотипом и 8 разделами.
- [ ] «Liquid Glass и цвета»: тумблеры и слайдеры двигаются, тема перерисовывается.
- [ ] «Приватность и Призрак»: «Режим Призрак» переключается (проверить статус «в сети»
      с другого аккаунта), «Читать без галочек» — сообщения читаются без двойных галочек.
- [ ] «Медиа и голос»: слайдер битрейта 16–128 kbps.
- [ ] Все 8 разделов открываются без краша.

## 4. Проверка ключевых функций

| Проверка | Как |
|---|---|
| Ghost-режим | Второй аккаунт: у вас статус «был(а) недавно», «печатает…» не появляется |
| Антиреклама | Открыть крупный канал со спонсорскими — блок исчез |
| Блокировка скриншотов | Настройки Spectra → Запрет скриншотов → `adb shell screencap` даёт пустой кадр |
| Локальный PIN | Nekogram Passcode уже работает — поставить PIN и проверить вход |
| Тема Spectra Dark | Настройки → Темы → импорт `Spectra_Dark.attheme` (доп. способ установки темы) |

## 5. Известные ограничения v1.0

- Функции с хранилищем `SpectraConfig.*` (анти-удаление, история правок, Дзен,
  калькулятор, сниппеты, анти-фишинг, дата регистрации, 120 FPS, скрытие Stories и др.)
  включаются патчами из `docs/spectra/HOOKS.md` — их UI готов, поведение подключается хуками.
- Liquid Glass-панели оптимизированы под Android 12+ (RenderEffect); на Android 8–11
  используется программный blur, на Android 5–7 — полупрозрачный fallback.
- Сборка в CI занимает 25–60 минут (нативные библиотеки собираются через CMake).
